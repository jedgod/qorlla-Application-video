# Release acceptance checklist

- [ ] Actual Qorlla production origin verified, TLS and deep-link association configured
- [ ] Desktop installer built, signed, notarized (macOS) and malware-scanned
- [ ] Desktop navigation, window-opening, CSP, permission and download security reviewed
- [ ] Android AAB signed and tested on physical Android devices
- [ ] iOS IPA signed and tested on physical iPhones; App Store review completed
- [ ] Authentication, logout, session revocation and CSRF verified per platform
- [ ] Camera, mic, screen-share, backgrounding, reconnection and push behavior verified
- [ ] TURN/cross-network/media tests and Qorlla 15 release gates completed
- [ ] Support, privacy, consent, data retention and accessibility reviewed
- [ ] Versioning, auto-update, crash reporting and rollback validated
