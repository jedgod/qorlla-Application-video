# Qorlla Group Call History v1.0

Additive PostgreSQL history projection, idempotent committed-event projector, authenticated Recent Calls API, framework-neutral browser client, and Node unit tests.

Run `npm test` and `npm run check` (Node 20+). Integrate using `docs/INTEGRATION.md`. The package is an **integration candidate**, not a claim of production certification. No existing repo files are modified.
